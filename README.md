# aprendizados

Documentação do que eu aprendo fazendo: infraestrutura, ferramentas e
configurações. Cada tema traz o **guia**, para qualquer pessoa conseguir
repetir o processo, e o **relato**, com o que eu fiz de verdade, inclusive os
erros e o que eu aprendi com eles.

## Temas

| Área | Tema | Resumo | Data |
| :-- | :-- | :-- | :-- |
| 🔐 Git | [Assinatura de commits](git/assinatura-de-commits/README.md) | Assinar commits e tags com SSH ou GPG, reassinar histórico já publicado e usar o Vigilant mode do GitHub. | 09/2026 |

## Como cada tema é organizado

```text
<area>/<tema>/
├── README.md        ← índice do tema e resumo rápido
├── 00-...md         ← capítulos do guia, em ordem
└── NN-relato.md     ← o que eu fiz, errei e aprendi
```
